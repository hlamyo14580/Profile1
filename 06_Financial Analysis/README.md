# **Financial Performance & Analysis**

→ Descriptive: What happened to overall financial performance?
Income Statement Analysis

→ Descriptive + Diagnostic: How has profitability changed, and what is driving the movement?
Balance Sheet Analysis

→ Descriptive + Diagnostic: Can the business meet obligations while supporting growth?
Cash Flow Analysis

→ Descriptive + Diagnostic: Does accounting profit convert into cash?
Actual vs Budget Performance

→ Diagnostic: Why is actual performance different from plan?
Regional Performance

→ Diagnostic → Prescriptive: Which regions are driving growth, profitability and budget performance?

The strongest LinkedIn message is therefore:

**DATA → INSIGHT → EXPLANATION → OUTLOOK → ACTION**
